Validatore tabelle eDNA

Controlla la tabella dei campioni prima dell'analisi e genera i file TSV per la pipeline. Tutto avviene nel tuo browser: il file non lascia il computer.

Preparazione del validatore…

1. Scegli il tipo di dati

Che tipo di dati contiene il file? La risposta vale per tutte le schede.

2. Carica la tabella

3. Controlla le schede e valida

4. Report

5. Controlla i file sul server

Dopo aver scaricato i TSV, puoi verificare che tutti i file FASTQ indicati esistano davvero sul server Raganella. Scarica lo script, caricalo sul server insieme ai TSV con FileZilla e lancia, dalla cartella che li contiene:

bash controllo_server.sh

Scarica controllo_server.sh

Lo script legge soltanto: non modifica né cancella nulla sul server. I dettagli sono nel manuale d'uso.

Ogni messaggio riporta un codice (es. E04, W02) spiegato nel manuale d'uso.
